# smart_mirrow

Суть проекта: зеркало с полупрозрачным стеклом, за которым стоит монитор. Raspberry Pi выводит поверх изображения полезную информацию. Плюс датчики движения - зеркало включается, когда подходит человек, и выключается, когда уходит.

Компоненты: 
- Raspberry Pi
- монитор
- зеркало Газелла
- датчик присутствия
- рамка
- провода
- питание
- и др.

Возможности: 
- показ времени
- показ погоды
- показ календаря
- включение при подходе человека

Идея, которой вдохновились в плей-листе: https://www.youtube.com/playlist?list=PLtkX2gOMBoVODOkil56UYYu46l91xzMJO
